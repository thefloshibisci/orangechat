## 本次 UI 修复

1. 主动消息与额外注入使用项目主题顶栏、背景、卡片边距和分组间距。
2. 助手基础设置的上下文数量、背景透明度在拖动中即时更新，松手后保存；上下文 0 仍表示不限制。
3. 显示设置的 19 个滑块即时显示当前数值，字号预览随拖动变化；保存回流不能冲掉另一滑块正在编辑的数值。

## 验收步骤

1. 在不同主题和界面材质下进入主动消息、额外注入，再返回其他设置页，检查顶栏、背景、分组、边距及滚动风格一致。
2. 连续拖动助手上下文数量和背景透明度，观察数字及背景预览；离开再进入，确认停手后的值保存，切换助手后显示对应值。
3. 拖动显示设置中的字号、透明度、挂件偏移和缩放，手指未松开时数字即变化；连续快速操作两个滑块，检查没有数字回弹，离开重进仍保存。
4. 在测试会话中导入图片、文档及空文件，检查失败导入不留下 0B 文件；重新使用已有附件不重复复制。
5. 文件管理多选删除后，确认框应立即关闭，操作完成后刷新；检查聊天文字、消息身份和重新生成分支保留，被删除的附件不再发送给模型。
6. 使用扫帚清理失效附件，或按时间选择文件。操作后重启，检查工具历史、普通聊天和主动消息可继续工作，共享引用的附件不会被自动回收误删。
7. 自动备份默认关闭。选定本地目录后启用，执行立即备份并确认可恢复；恢复后应保持自动备份关闭。WebDAV、S3 与系统后台调度另按实际环境验证。
