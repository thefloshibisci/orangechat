# 聊天覆盖恢复白屏：恢复入口修订

## 本次修改

- 有待恢复任务时先进入选择页，用户点击“继续恢复聊天记录”后才解析备份并创建聊天数据库依赖，避免启动即自动重试同一任务。
- “取消待恢复任务并进入应用”只清除待恢复指针，不依赖备份 JSON、Room 或设置加载。保留原 ZIP 和暂存文件；后续重新选择备份时清理旧暂存。运行中的任务仍先等待事务回滚，不能提前放行数据库读写。
- 先前的崩溃标记不会跳过恢复选择页。
- 增加“复制启动诊断”：仅本机记录启动阶段；Android 11 及以上读取系统进程退出原因，若系统保存了 ANR trace 则附上。诊断不会主动上传，也不读取备份聊天内容。旧版本没有阶段标记时会明确显示无记录。
- 增量、同 ID 覆盖、保留不在备份内的会话、五模块摘要提示词均保持原有规则。
