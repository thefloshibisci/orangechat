## 恢复规则：以此为准

| 备份会话与本机的关系 | 增量式恢复 | 覆盖式恢复 |
| --- | --- | --- |
| 备份中有，本机没有同 ID | 新增整段会话 | 新增整段会话 |
| 备份中有，本机已有同 ID | 完全跳过，保留本地原样 | 以备份完整替换本机会话 |
| 本机有，备份没有 | 保留 | 保留 |

增量跳过同 ID 会话时，不改本地消息、分支选择、压缩状态、元数据、收藏与搜索索引；也不复制只被跳过会话引用的附件。不会逐条消息合并。恢复结果显示实际新增和跳过数量。

不存在的助手映射到导入时选定的本机助手，失效时采用本机有效助手；外来工作区路径不导入，不匹配的文件夹归属清空。
