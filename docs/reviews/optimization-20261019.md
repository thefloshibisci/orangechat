## 本次发现并修复

| 路径 | 原因与影响 | 修改 |
|---|---|---|
| 微信/QQ 机器人 | 冷会话没有加载消息就发送，触发完整历史保护；发送后才订阅完成广播也可能漏掉瞬间完成事件 | 先完整初始化，保持机器人指定助手；等待本次发送 Job；超时取消该 Job；所有出口释放引用，避免旧回复被转发 |

| 撤销附件 | 删除会话立即回收文件，撤销只恢复数据库引用 | 撤销窗口暂时持有附件，结束后重新核对数据库和设置引用；其他删除操作不能回收仍被撤销窗口持有的文件 |
| 延迟标题/建议 | 删除并恢复后，删除前发出的模型请求可能回写旧结果 | 增加会话生命周期版本校验；请求期间持有会话引用；恢复整个过程不可被取消拆开 |
| 设置背景/头像挂件 | Compose 中同步解码原始大图 | 使用 Coil 异步解码与按布局尺寸采样，保留既有滑块即时预览 |
| 气泡模糊背景 | 关闭实时模糊时仍解码，且本地图片按原始尺寸分配 | 只在功能启用时加载屏幕尺寸的软件位图；关闭/换图即释放 UI 引用，屏幕尺寸变化后重新请求 |
