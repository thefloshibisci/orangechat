# 同一助手使用多个工作区

助手设置可以同时勾选本地、SSH 工作区，并另选聊天默认目标。旧版 `workspaceId` 保留为默认目标；新 `workspaceIds` 保存多选绑定。会话中的旧 `ConversationConfig.workspaceId` 不再覆盖助手的实时设置。

每次工具执行重新读取助手绑定、默认目标、工作区记录及审批配置。`workspace_id` 是可选参数：省略时读取实时默认值；显式填写时只接受绑定列表中的精确 ID，写错就报错，不按名称猜测。目标已解绑、删除、未就绪或连接失败都会报错，不回退本地。执行开始后固定本次机器快照，避免同一次读写过程中换连接；下一次执行重新解析。

结果首行显示工作区名和本地/SSH 用户、主机、端口。SSH 身份来自已保存且校验主机密钥的连接配置，不将它伪装为服务器返回的 hostname。结果 metadata 保存 `workspace_id`、`workspace_root`、`machine`，文件按钮据此导出；多工作区时不把没有目标信息的普通 sandbox 链接发送给默认机器。

失败结果同样保留机器抬头和失败状态，不会显示为已生成文件。目标尚未解析成功时标记“未执行”及请求目标，不冒充已在某台机器执行。

## 定时工作流

工作区文件或 shell 步骤可以省略 `args.workspace_id`，执行时使用作者助手的当前默认工作区，与聊天调用一致。显式填写时使用指定 ID，并按助手当前绑定校验；传输步骤仍需保存 `source_workspace_id` 和 `destination_workspace_id`。后台继续沿用已有审批规则，远程失败照常失败。

旧任务的参数原样保留，读取、展示和执行都不会把省略值改写为某个本地工作区。用户之后更改助手默认工作区时，未填写 ID 的任务也会使用新的默认；需要指定另一工作区时才填写 ID。

命令非零退出或返回超时会记录工作流失败，后续步骤停止；这类失败摘要保留结果中的机器标识。

## 文件传输与路径

`workspace_transfer_file` 支持双向复制单个二进制/文本文件，必须显式指定两端 ID 和绝对路径。默认 `overwrite=false`，硬上限 **20 MiB**。先检查源大小和目标是否存在，再读取；读取过程继续限流，防源文件增长。完整读取后发布，普通失败清理暂存文件，取消/断线可能遗留独立暂存文件但不修改最终文件。默认不替换同名文件：远程使用 OpenSSH hardlink 扩展原子发布，扩展不可用时直接报错；不会为兼容而放松覆盖保护。两端远程操作均不退回本地。

允许覆盖仅适用于文件，同名目录会被拒绝并保留。

AI 文件路径及 shell 的 `cwd` 限于选定根目录：归一化 `.`/`..` 后检查完整目录边界，本地检查 canonical path，远程检查 SFTP realpath，拒绝指向根外的符号链接。人手操作的系统文件浏览器保留原用途。

**这不是 shell 的整机沙箱。** 任意 shell 内容仍以该 SSH/本地执行账户的权限运行，`cwd` 校验不会限制命令内任意脚本的文件访问。需要强隔离时应另配受限账户/容器；不能声称提示词或参数校验已经提供这种隔离。文件工具本身仅能访问声明的工作区根，技能目录由专用 skill 工具读取。

## 验证边界

回归用例覆盖旧会话绑定覆盖问题、已构建工具热切换/解绑、审批收紧、远程失败不调用本地 shell、机器标签、单次连接快照、双向二进制传输/同名保护/20 MiB 限额、越根和符号链接、旧任务保留缺省参数及默认变化。SSH 主机密钥/存储/连接控制沿用现有回归。单元测试使用合成数据，不执行真实邮局或生产服务器命令；真实手机与 SSH 端到端体验仍需实机验收。
