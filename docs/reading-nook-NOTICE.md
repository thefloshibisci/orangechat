# Reading Nook reference and attribution

The native 共度「一起读」room adapts the bookshelf, reading progress, source-anchored annotations and companion replies concept from [Reading Nook](https://github.com/thefloshibisci/reading-nook).

- Reference commit: `275e022b0d6fe00ef932a7313a984df42793c036`.
- Reference `app.py` Git blob: `f39fa6d13ad48fde56546ee64ba48bd23b16e476`.
- TXT chapter-heading patterns in `ReadImporter.kt` are adapted from its MIT-licensed implementation.
- Copyright (c) 2026 reading-nook contributors. The full MIT notice is included in the App at `assets/licenses/reading-nook.txt`.

The Compose room, bounded native EPUB text importer, local atomic storage, chat consent and tool integration are implemented for OrangeChat. No Reading Nook server, four-digit passcode gate, optional DeepSeek calls, source UI assets or remote book storage are included. The existing OrangeChat license continues to apply to the application.
