# 共度 小红书接入

共度复用聊天附件菜单中原来的共看位置，首版仅接入小红书。原共看的网页播放、抓帧与控制面板已移除。旧导航会进入新页面；聊天历史和用户安装的插件文件不会删除。绘图插件的通用发图能力保留。

## 连接自己的服务

1. 从聊天附件菜单打开共度，在设置中填写完整 MCP 服务地址，例如 `https://你的域名/mcp`。手机的 `localhost` 只指手机自身。
2. 如服务启用了鉴权，将访问令牌填入单独的令牌栏，保存后连接。APP 验证 MCP 握手和小红书工具，配置保存不等于连接成功。
3. 扫码授权后检查登录状态。服务连接与小红书账号登录是两个状态。
4. 打开“让当前助手使用小红书”。仅将该服务关联到当前聊天的助手，其他助手不变。新发现的公开互动工具默认需要确认，可在原 MCP 设置中调整。

推荐与搜索从服务返回真实笔记；点击笔记可查看正文并送到当前聊天。实际发帖和互动由服务发现的 MCP 工具在聊天中执行。发布工具超时为 600 秒，失败或超时不代表可安全重复发布，需先核对平台结果。

## 视频

“让机看视频”和 AI 工具 `gongdu_read_video` 从真实媒体提取六个时间点的画面，结合服务提供的字幕直链读取 SRT。当前聊天模型必须启用图片输入。首版限制 3 分钟与 40 MB，仅支持小红书媒体 CDN；签名过期需刷新笔记。

首版不提供原始音轨转写，不宣称看过未采样的动作或听过声音。没有可用字幕时会明确告诉模型只分析画面。

## 消息门铃

服务需提供 `list_notifications`。启用前读取通知并建立基准，旧通知不会重放。以后按事件 ID 去重，待处理事件保存在设置中；只有聊天中出现持久化的事件收件记录，才确认投递。读取通知可能同步平台已读状态。

门铃绑定指定聊天，仅 APP 处于前台时约每分钟检查。进程退出、强制停止与系统休眠后的即时提醒没有保证。服务器推送、系统通知渠道和后台部署尚未提供。

没有后台服务时可以完成 APP 配置和查看未连接状态；真实扫码、发帖、通知及视频兼容性需要部署后实测。本次不包含服务部署、账号登录、公开发帖或设备数据修改。
