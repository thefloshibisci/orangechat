# 共度 小红书接入

共度复用聊天附件菜单中原来的共看位置，首版仅接入小红书。原共看的网页播放、抓帧与控制面板已移除。旧导航会进入新页面；聊天历史和用户安装的插件文件不会删除。绘图插件的通用发图能力保留。

## 连接自己的服务

1. 从聊天附件菜单打开共度，在设置中填写完整 MCP 服务地址，例如 `https://你的域名/mcp`。手机的 `localhost` 只指手机自身。
2. 如服务启用了鉴权，将访问令牌填入单独的令牌栏，保存后连接。APP 验证 MCP 握手和小红书工具，配置保存不等于连接成功。
3. 扫码授权后检查登录状态。服务连接与小红书账号登录是两个状态。
4. 打开“让当前助手使用小红书”。仅将该服务关联到当前聊天的助手，其他助手不变。新发现的公开互动工具默认需要确认，可在原 MCP 设置中调整。

推荐与搜索从服务返回真实笔记；点击笔记可查看正文并送到当前聊天。实际发帖和互动由服务发现的 MCP 工具在聊天中执行。发布工具超时为 600 秒，失败或超时不代表可安全重复发布，需先核对平台结果。

## 视频

“让机看视频”和 AI 工具 `gongdu_read_video` 从真实媒体按时长抽帧，默认以两秒间隔为起点，全片概览最多 24 帧，长视频会放宽间隔。画面合成带秒数的拼图，便于按顺序查看，也避免大量图片占满上下文。可以在笔记详情填写补看起止秒数，或让机通过工具的 `start_seconds`、`end_seconds` 指定 30 秒以内的片段，`frame_interval_seconds` 可设为 0.5～5 秒。概览只说明采样画面，快速动作仍可能遗漏，需要时应分段补看。

单次超过 24 帧预算时会自动放宽间隔；需要更密的画面请缩短补看片段。机自主补看还需要在共度设置中授权当前助手使用小红书。当前聊天模型必须启用图片输入。视频限制 3 分钟与 40 MB，仅支持小红书媒体 CDN；签名过期需刷新笔记。

APP 从视频中解码所选范围的原声音轨（全片概览对应全片声音），转成单声道 16 kHz WAV。支持原生音频输入的聊天模型会同时收到音轨，可以分析对白、说话语气及音乐、环境音；其判断仍需以实际音频为依据。沿用已有模型音频模式：Google/Gemini 可自动识别，兼容 OpenAI Chat Completions 通道需要在模型设置中确认音频输入；Responses 等未实现音频载荷的通道不会盲目发送。

模型不能直接听声音时，使用“语音设置”中已选的文件识别服务转写对白，复用其密钥，不另存一套配置。目前支持 SiliconFlow、MiMo、以及 OpenAI Realtime 配置对应的文件转写接口；火山实时配置尚不支持文件转写。只有 ASR 文字时不能判断音乐、音效、语气或声纹。没有 ASR 配置、音轨缺失或服务失败时，仍可读取画面及可用平台字幕，并明确报告声音未提供；不会把字幕或成功提示当成听过原声。

## 消息门铃

服务需提供 `list_notifications`。启用前读取通知并建立基准，旧通知不会重放。以后按事件 ID 去重，待处理事件保存在设置中；只有聊天中出现持久化的事件收件记录，才确认投递。读取通知可能同步平台已读状态。

门铃绑定指定聊天，仅 APP 处于前台时约每分钟检查。进程退出、强制停止与系统休眠后的即时提醒没有保证。服务器推送、系统通知渠道和后台部署尚未提供。

没有后台服务时可以完成 APP 配置和查看未连接状态；真实扫码、发帖、通知及视频和音轨兼容性需要服务接通后实测。Zeabur 部署清单和验收步骤见 `deploy/gongdu/README.md`；账号登录仍需本人扫码，公开发帖及设备数据修改不是部署验收的一部分。

## 一起听

一起听使用原生 Compose 音乐房间和 Media3 媒体服务。服务端安装方法见 `deploy/listen/README.md`，APP 的“连接”页填写该服务的 HTTPS 根地址与访问令牌，然后用网易云扫码登录。登录凭据保存在自己的音乐服务上。

“找歌”提供搜索、每日推荐、私人雷达和歌单。点播放开始原生播放，返回聊天后显示迷你播放条。待播列表标明歌曲由用户或助手加入及点歌留言。歌词支持点击定位、跟随当前句和选择最多八句分享，歌曲手记可保存正文、心情、喜欢的句子和标签。

“让当前助手一起听”需要在当前聊天明确启用，绑定该聊天与助手。启用后 `music_tool` 提供当前状态、搜索、歌词、队列、送歌和排歌，输入上下文只在真实播放/缓冲时加入当前歌词与进度。撤销授权对后续工具及在途助手点歌生效。用户在另一聊天主动播放会新建该聊天的队列，并撤销旧聊天的陪听权限。助手在播放器停止时点歌，会准备歌曲等待用户点播放。

歌卡随普通消息和工具结果持久保存，点卡片的播放键才发起播放。音乐来源为 one-earbud 的网易云客户端适配，固定来源与授权说明保存在 `deploy/listen/NOTICE.md`。耳语的音乐房间和手记交互作为设计参考，原生实现独立编写。

本地验证不使用真实账号。实际扫码、曲库可用性、手机后台与锁屏控制仍需安装后验收。当前提供给模型的是歌曲资料、歌词和进度。原声音频输入与频谱分析尚未接入。

## 一起读

从共度大厅的小鱼卡片进入原生书架，使用系统文件选择器导入 TXT 或未加密 EPUB。TXT 自动识别常见编码并按章节标题拆分；EPUB 按书内阅读顺序提取正文、封面与本地 PNG/JPEG/GIF/WebP 插图，不执行脚本或加载远程资源。支持图片组成的章节，图片按完整比例显示；不支持 PDF、扫描文字识别及 EPUB 原版 CSS 排版。解析与文件大小限制失败时会显示原因，保留已有书架。

阅读页和所有面板统一使用共度字体及法式蓝笺日夜配色，保留旧纸页外观兼容。正文默认 20，外观面板提供“默认 20”快捷恢复，保留已有自选字号。提供目录、滚动、按实际文字尺寸排版的单页/宽屏双页、字号、行距、段距、字距和可移动阅读尺。窄屏双页自动收拢为单页。

外观中的四张图示卡选择平移、覆盖、仿真或上下翻页，随蓝笺日夜配色并持久保存；从滚动选择效果会进入单页，原有双页保持。上下翻页为竖向逐页，连续滚动仍是独立阅读方式。滑动越过阈值后松手或点击前后页按钮播放转场，仿真呈现纸页折面与阴影，当前不做随手指实时卷曲。取消/短滑不改书签；转场期间旧页不可批注，完成后才发布助手可读的当前页范围。动画遵循系统时长设置。

页码随屏幕、字体与间距变化；持久书签使用章节、段落与 UTF-16 字符偏移，助手不修改人的书签。再次导入相同文件复用已有书籍、进度和批注。点原文可选择连续文字，保存划线与想法；批注与回应区分我的内容和助手内容，可回到原文或将书摘带回聊天。

“让当前助手陪我读”仅授权当前书籍、当前聊天和当前助手，重启后需重新开启。打开另一本书，或在另一聊天打开书籍，会撤销旧授权。`reading_tool` 支持实际屏幕分页片段及字符坐标、按页返回已读章节段落、当前聊天的批注串与回应、原文批注和阅读札记。引用纠偏仅在已读范围的附近段落内进行。分页模式以当前显示页末字符为边界，排版未完成时收紧到书签位置；滚动模式以当前段为边界，不允许模型读取之后的正文。插图在本地阅读器展示，工具仅提供替代文字，不能因此声称模型看过图片。阅读房间打开时，有限的当前原文和前文可随聊天请求提供给助手；返回聊天后可从阅读条重新打开书架。书名、原文和批注始终作为引用资料处理。

「札记与备份」提供当前书籍、聊天、助手的阅读记录与双方札记。人类阅读时间只计前台且最近有交互的时间，闲置超过一分钟停止计时；助手实际读取记录保存片段与时间戳，时长始终为零，不冒充人的阅读时间。阅读数据以本地原子文件持久保存。

从共度入口分享会把书摘加入当前聊天的发送队列；从聊天顶部阅读条打开的阅读弹窗分享，会先填入输入框，点击发送后才保存为消息。正在编辑历史消息时会提示先完成编辑，避免覆盖旧消息。已发送的书摘以普通消息文字保存，聊天中显示为书摘卡片，不需要以后还能找到原书。

阅读专用 ZIP 备份含整个本地书架、所有原图、书签、批注、阅读记录、札记及设置快照，并逐文件保存 SHA-256 校验。恢复先显示新增和跳过的书籍，确认后仅合并新增书籍；已有书籍、当前外观保留，不恢复陪读授权。文件不完整或内容无效时拒绝恢复。当前书籍可单独导出含当前聊天批注和札记的独立 Markdown 或重新排版 EPUB（均包含原图）。备份不自动上传；应用完整备份、系统备份、云同步仍是独立边界。移出书架会删除本机书籍、对应批注与记录。导入/导出的手机文件选择器和实际阅读手感仍需设备验收。

交互参考 Reading Nook 的书架、进度和双人批注；TXT 拆章模式依照 MIT 授权适配，见 [reading-nook-NOTICE.md](reading-nook-NOTICE.md)。图片、坐标、札记与便携导出的功能参考 coread，原生实现独立编写，见 [coread-NOTICE.md](coread-NOTICE.md)。没有接入两个项目的额外模型预读、Node 或网页阅读服务，也未移植全八套主题。
